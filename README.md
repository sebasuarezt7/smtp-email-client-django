# SMTP Email Client Django

Final project for CPAN226 - Network Programming.

## Description
This project implements an email web application using Django and Python. It uses the SMTP protocol to send emails with support for multiple recipients (CC) and file attachments.

## Tech Stack
- Python
- Django
- SMTP

## Features (Planned)
- Send email via SMTP
- Multiple recipients (CC)
- File attachments
- Input validation
- Error handling
- Optional email history storage
